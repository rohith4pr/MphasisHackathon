Two-phase API flow
Phase 1 — Analyze
POST/api/v1/incidents/analyze
Angular → Spring Boot
→ AiEnrichmentService (classify log)
→ Python graph.invoke(initial_state)
→ Agents 1, 2, 3 run
→ Graph pauses at interrupt
→ Returns session_id + RootCauseResult
Phase 2 — Approve & finalize
POST/api/v1/incidents/analyze/{id}/approve
Analyst approves/rejects in UI
→ Spring Boot proxies to Python
→ graph.update_state(feedback)
→ graph.invoke(None, config)
→ Agent 4 resumes from checkpoint
→ Returns IncidentReport
